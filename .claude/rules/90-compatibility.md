# Rule: Compatibility

Compatibility is a measured matrix, not a claim.

Track:
- title identifier
- version/build
- boot stage
- status
- tested configuration
- last known good commit
- failure signature
- workaround
- confidence
- regression test

Do not claim "works" from one successful launch. Distinguish:
BOOT, MENU, IN-GAME, PLAYABLE, STABLE, COMPLETE where appropriate.
