# Autonomous Workflow

1. Check git status.
2. Run baseline tests.
3. Run relevant real-title regression.
4. Inspect the highest-priority architectural issue.
5. Characterize before changing.
6. Make one small reversible change.
7. Build.
8. Run focused tests.
9. Run full tests.
10. Run real-title regression if relevant.
11. Update documentation.
12. Repeat only while the next task remains low-risk and evidence-backed.
13. Stop on ambiguity or scope expansion.

Time available is not permission to expand scope.
