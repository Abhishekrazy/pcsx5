# Skill: Game Running

When asked to make a title run:

1. identify exact title/version
2. establish baseline
3. reproduce
4. capture logs
5. identify boot stage
6. identify first divergence
7. classify subsystem
8. compare known compatibility data
9. form hypothesis
10. implement narrow fix
11. regression test
12. update compatibility record

Do not call a title fixed merely because the process no longer crashes.
