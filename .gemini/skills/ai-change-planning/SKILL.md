# Skill: AI Change Planning

## Purpose
Convert a request into a bounded engineering plan.

## Procedure
1. Read GEMINI.md.
2. Read applicable rules.
3. Identify task level.
4. Search architecture docs.
5. Search ADRs.
6. Search existing implementations.
7. Search reusable contracts.
8. Establish Claims vs Reality.
9. Identify owner.
10. Identify dependencies.
11. Identify behavior changes.
12. Identify tests.
13. Identify runtime validation.
14. Define stop conditions.
15. Produce plan before significant implementation.

## Output
Goal
Current Reality
Scope
Owner
Existing Contracts
ADR Impact
Files
Tests
Runtime Validation
Risks
Stop Conditions
Plan Status
