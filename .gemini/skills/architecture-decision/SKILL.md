# Skill: Architecture Decision Record

Create an ADR when a durable decision is made.

Before creating:
1. search existing ADRs
2. detect duplicates
3. detect conflicts
4. identify affected architecture

ADR must contain:
Context
Decision
Why
Alternatives
Consequences
Security/Integrity Impact
Compatibility Impact
Versioning
Migration
Testing
Implementation constraints
Related ADRs

Status:
Proposed
Accepted
Rejected
Superseded
Deprecated
Retired

Never rewrite history. Supersede old decisions.
