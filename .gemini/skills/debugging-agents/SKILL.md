# Skill: Debugging With Agents

For difficult failures:

Scout: locate relevant code.
Reproducer: establish deterministic failure.
RE: inspect binary/trace.
Memory: validate addresses/mappings.
CPU: validate execution state.
Kernel: validate OS/HLE semantics.
GPU: validate rendering/resource behavior.
Game: analyze engine/runtime.
Test: build minimal regression.
Reviewer: challenge conclusion.

Agents return evidence, not competing patches.

Coordinator integrates.
