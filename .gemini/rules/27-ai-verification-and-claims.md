# AI Verification and Claims

Every task report must include:

- scope
- files changed
- tests and exact results
- runtime/manual verification
- Claims vs Reality
- unverified items
- architecture invariants checked
- Git status
- remaining gaps
- next recommended task

Use exact language.

"Tests pass" means tests pass.

It does not mean:
- games work
- architecture is correct
- performance is acceptable
- release is safe

Never overclaim.
