# Reverse Engineering Governance

RE is evidence gathering.

Required workflow:

Observe
-> Capture
-> Isolate
-> Hypothesize
-> Instrument
-> Reproduce
-> Compare
-> Corroborate
-> Implement
-> Regression test

Evidence hierarchy:
1. reproducible runtime observation
2. multiple independent traces
3. binary/metadata evidence
4. controlled experiment
5. documented external evidence
6. single observation
7. intuition

Single-observation hardware conclusions must remain hypotheses.

Never encode a guessed register/NID/ABI as fact.
