# Git and Repository Governance

Never perform without explicit authorization:
- git reset --hard
- git clean -fd
- force push
- broad deletion
- history rewrite
- destructive branch operations

Before significant work:
- inspect status
- inspect branch
- preserve user changes

After work:
- inspect diff
- inspect status
- report untracked files
- report generated artifacts
- report tests

Do not commit unless explicitly requested.
