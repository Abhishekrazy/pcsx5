# Technology Governance

Every dependency is provisional.

Before adding:
- problem
- existing capability
- why current stack cannot solve it
- runtime/build impact
- license
- binary size
- maintenance
- security
- platform constraints
- removal plan

Before removing:
- usage inventory
- replacement
- compatibility
- build/test evidence

Technology classification:
KEEP
ISOLATE
RE-EVALUATE
REMOVE-LATER
UNKNOWN

C++20 remains baseline.
