# Claims vs Reality

Maintain:

| Claim | Spec | Code Evidence | Test Evidence | Runtime Evidence | Status |
|---|---|---|---|---|---|

Status:
PASS
PARTIAL
FAIL
UNKNOWN

Evidence rules:
- Unit test proves only the exercised contract.
- Integration test proves only the exercised path.
- Boot proves boot behavior, not playability.
- A menu proves menu reachability, not gameplay.
- A benchmark proves measured workload, not universal performance.
- Code existence proves implementation existence, not correctness.
- Documentation proves specification, not implementation.

Forbidden without evidence:
"fully complete"
"fully compatible"
"production ready"
"100% stable"
"fixed"
"verified"

Use precise alternatives.
